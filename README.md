Aplikasi web interaktif untuk pengolahan data statistika deskriptif yang dilengkapi dengan perhitungan statistik, visualisasi grafik, serta fitur pengelolaan data menggunakan **HTML5, CSS3, JavaScript (ES6+), Plotly.js, dan PapaParse**.

Project ini dibuat untuk memenuhi tugas Ujian Tengah Semester (UTS) mata kuliah Statistika.

---

## Fitur Utama

### 1. Input dan Pengelolaan Data

- Input data secara manual.
- Upload file CSV untuk memasukkan data.
- Membaca dan memproses data CSV secara otomatis.
- Menampilkan data yang berhasil diunggah.
- Download data dalam format CSV.
- Menyediakan data sampel mahasiswa sebagai bahan pengujian.
- Validasi data sebelum dilakukan perhitungan.

### 2. Perhitungan Statistik Deskriptif

Aplikasi menyediakan beberapa parameter statistik deskriptif, di antaranya:

1. Jumlah Data (n)
2. Total Nilai (Σx)
3. Mean (Rata-rata)
4. Median (Nilai Tengah)
5. Modus (Nilai yang Sering Muncul)
6. Nilai Minimum
7. Nilai Maksimum
8. Range (Jangkauan)
9. Varians
10. Standar Deviasi
11. Kuartil 1 (Q1)
12. Kuartil 3 (Q3)
13. Interquartile Range (IQR)
14. Deteksi Outlier

### 3. Visualisasi Data

- Histogram distribusi data.
- Grafik Boxplot untuk melihat persebaran data.
- Diagram batang distribusi frekuensi.
- Tabel distribusi frekuensi.
- Visualisasi hasil pengolahan data secara interaktif.

### 4. Fitur Tambahan

- Download hasil pengolahan data.
- Upload dataset dari file CSV.
- Menampilkan data yang telah diurutkan.
- Kamus rumus statistika.
- Penjelasan istilah-istilah dalam statistika.
- Tampilan responsif yang dapat digunakan melalui komputer maupun perangkat mobile.

## Cara Menjalankan Aplikasi

Aplikasi ini berbasis web dan dapat dijalankan melalui browser tanpa memerlukan backend khusus.

1. Download atau clone repository project.
2. Buka folder project.
3. Jalankan file `index.html` menggunakan browser.
4. Masukkan data secara manual atau unggah file CSV.
5. Klik tombol proses untuk mendapatkan hasil perhitungan statistika.
6. Lihat hasil perhitungan dan visualisasi grafik.
7. Gunakan fitur download untuk menyimpan data hasil pengolahan.
